# このサイトの使い方

:::note このサイトについて
『ダンジョン・オブ・ザ・マーダー』（マダミス7）の制作INDEX（改訂版）。2026-10-06に行った作者修正指示の反映・総点検・校正・仮想プレイの結果をそのまま載せている。改稿前（Ver3.4）の制作者確認盤は「参照・旧版」から開ける。
:::

## まず読むページ

| ページ | 内容 |
|---|---|
| はじめに ＞ PROJECT_MASTER | 全体の案内。確定事項・廃止事項・未解決事項（作者判断待ち） |
| はじめに ＞ 作者指示の反映表 | 10/06の修正指示の一つ一つを、どこにどう反映したか |
| はじめに ＞ REPORT | 評価・主な改善点・残った課題 |
| ルール ＞ 追跡者の位置の仕様案 | 作者判断待ちの3案 |

## 画面の見かた

| 場所 | 役割 |
|---|---|
| 左のサイドバー（左列） | 大題。HO・読み合わせ・カードなどの大きな分類 |
| 左のサイドバー（右列） | 中題。選んだ大題の中のページ一覧。開いているページの見出しも、その下に並ぶ |
| 中央 | 本文 |
| 右のサイドバー | 修正案。必要なときだけ開く。たたむと細い帯になる |

- サイドバーの幅は、境目の線をドラッグして変えられる（左右とも。左は大題と中題の境目も動かせる）
- 幅はこの端末に記憶される。たたむ・開くは上部のボタンか、サイドバーの「＜」「＞」で行う

## 本文の見かた

| 表示 | 意味 |
|---|---|
| 色付きの名札 | 読み合わせの話者。ミレイユ＝薔薇色、ヴィオラ＝紫、リュシア＝緑、ガルド＝赤銅、レオン＝青、追跡者＝黒金 |
| 名札の「いれば」 | 分断した組など、その場にいる人だけが読む台詞 |
| 黒い帯 | アプリの画面に出る文（ライブセレクション、カードの配布など） |
| たたまれた「GM専用」 | GM・アプリ向けの指示。プレイヤー配布版には載らない |
| 修正F1 など | 仮想プレイの後に直した箇所（番号はCHANGELOG 5章） |
| 作者指示・追加設定・調整案 | 作者の指示で変えた所／こちらで補った設定／数値の仮置き |

## 修正案の残し方

1. 本文の直したい段落・台詞・表の行にカーソルを合わせると、右端に「✎」が出る（スマホでは、その行を一度タップする）
2. 「✎」を押すと右のサイドバーが開き、その箇所の修正案を書ける
3. 書いた内容は自動で保存される。「反映済み」にすると、一覧で区別できる
4. 修正案のある箇所には、本文の右端に印が付く（黄色＝未反映、緑＝反映済み）
5. 右のサイドバーの「このページ」「すべて」で一覧を見られる。「すべて」から、未反映の修正案をMarkdownで書き出して、Claudeに渡せる

## 共有保存（編集キー）

- 閲覧と修正案の表示には、キーは要らない
- 上部の「編集キー」から作者用の編集キーを入れると、修正案が共有保存（Cloudflare D1）に保存され、ほかの端末でも見られる。解除は30日間有効
- キーを入れていない間も、修正案は「この端末の下書き」として残る。あとで解除すると「下書きを共有へ送る」で送れる
- 同じ箇所を別の端末で同時に直した場合は、上書きせずに知らせる
- 保存先はこの作品専用（お母さんは大統領など他作品のメモとは混ざらない）

:::note 公開について
このサイトは、URLを知っている人なら誰でも読める（GitHub Pagesの公開サイト）。真相やGM情報も載っているので、プレイヤーにURLを教えないこと。修正案に個人情報やパスワードを書かないこと。
:::

| 印 | 意味 |
|---|---|
| PL配布 | プレイヤーに渡す物（HO・読み合わせ・カード・ルール）。ここに載っているのは制作メモ付きの作業版。配布用は改訂フォルダの 05_完成版/プレイヤー配布 |

| GM専用 | 真相・正答・隠し結果・進行を含む |
| 制作 | チェック結果・仮想プレイ・管理資料 |
| 参照 | 改訂元（Ver3.4）の仕様メモや旧版 |
