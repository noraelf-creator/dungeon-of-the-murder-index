### 1. どこへ向かうか（追跡者の行き先の部屋）

探索のあと、追跡者は次の順で行き先の部屋を一つ決め、その部屋へ向かって進む（P4〜P6は1部屋、P7〜P9は2部屋）。

| 順 | 行き先 | いつ | 飛ばすとき |
|---|---|---|---|
| ① | 《誘引》の2回：リックの居る部屋（物音に関係なく） | ヴィオラが《誘引》を仕込んだ次のフェイズから2回 | リックが誰にも同行していない・その部屋へ届かない |
| ② | **狙いの人の居る部屋**：P4＝**リック**（同行主の部屋）、P5〜P9＝**ヴィオラ** | P4〜P9 | 狙いの人が休息・行動不能・探索に出ていない・その部屋へ届かない |
| ③ | 物音の合計がいちばん大きい部屋 | P4〜P9 | 人のいない部屋は数えない |
| ④ | 同じなら、人の多い部屋 → 近い部屋 → 部屋の番号 | | |

- 物音（③）：探索した人1つにつき+1、重い部屋+2、攻撃魔法の人+2、リックの同行+1（《魔法剣》を使えば+2）、引きつける+5、リックの浸食（P4〜P5は+1、P6〜P7は+2、P8〜P9は0）。エドガーの部屋は+0（11/2）。
- エドガーは狙い（②）にならない。追跡者が原因のダメージも受けない（11/2）。
- 追跡者が動かない時期：P1〜P3（入口大広間で作り直している）、P10〜P12（守護核）。
- 休息した人は数えない（物音も出さない）。

### 3. 遭遇の回数の試算（400回ずつ。P5〜P8 に一度も遭遇しない回の率）

試し方：`tests/v4-helpers.js` の通し（P1〜P9）を、乱数の種を変えて400回ずつ。LS の選択はでたらめ。前＝11/3 の統合（c1c2001）、後＝この決まり。

| 遊び方 | 1回の遊びの遭遇（前→後） | P5〜P8 で0回（前→後） | P5〜P9 の最初の一撃の的（後） |
|---|---|---|---|
| 全員で同じ部屋（でたらめ） | 2.63 → 2.65 | 6.5% → 6.5% | ほぼヴィオラ（P4 はリック） |
| 全員で同じ部屋（調べ残し） | 2.39 → 2.38 | 11.0% → 11.0% | ほぼヴィオラ |
| 1〜2人だけ・ほかは休息 | 2.55 → 2.55 | 8.0% → 8.0% | ヴィオラ・ミクシィ・ミレイユに分かれる |
| 2人ずつ（調べ残し） | 2.38 → 2.56 | 11.3% → 8.8% | ほぼヴィオラ |
| 各自ばらばら（調べ残し） | 2.51 → 2.56 | 10.0% → 7.5% | ほぼヴィオラ |
| 各自ばらばら（でたらめ） | 2.88 → 2.71 | 5.0% → 4.3% | ほぼヴィオラ |

- 回数はほとんど変わらない。変わるのは「だれの所へ来るか」（P5〜P9 はヴィオラの居る部屋へ）。
- 遭遇が少ない（P5〜P8 で0回の回がある）のは、P4〜P6 の速さが1部屋のため（ptflow の調べと同じ）。増やすなら P4〜P6 の速さを2にする案（作者の判断待ち）。

## 案A：常に公開（易しい）
- 追跡者の位置をマップに常時表示。
- 長所：分かりやすい。初心者向け。

## 案B：気配で知らせる（推奨）
| 時期 | 表示 |
|---|---|
| P1〜P3 | 「入口大広間で再構築中」と固定表示 |
| P4〜P5 | マップに**気配の範囲**だけ表示（追跡者のいる部屋とその隣を、まとめて薄く赤く塗る）。どの部屋かは分からない |
| P6 | 守護者門に固定（窮地の演出） |
| P7〜P9 | 気配の範囲も消える。距離1・2の個人メモだけ（Ver3.4どおり） |
| P10〜P12 | 守護核で再構築中（固定） |

さらに「位置を知る手段」を用意する：
- **危険察知**（ミクシィ、MP1）：選んだ行き先と、その隣に追跡者がいるかが分かる。
- **守護監視室（U10）の部屋LS成功**：そのフェイズの終わりに追跡者の正確な位置を見る。
- **追跡環廊（L9）を深度2まで調べた後**：下層でも、フェイズ開始時に「追跡者の最後の記録位置」が分かる。

- 長所：探索の選択に「安全か、近いか」の判断が入る。技能と部屋に意味が出る。騒音を後で入れても、移動の仕組みはそのまま使える。
- 短所：実装（マップの塗り）が必要。
