# R14 P9 ― 祭壇前の崩壊

> P9の探索から帰還したあと、全員が祭壇前（L11）に集まった場面。
> 場面1の途中で接続痕を全員に公開。場面1の最後に分断のライブセレクション。場面2は結果表示のあと全員で読む。
> 配役：ミレイユ、ヴィオラ、リュシア、ガルド、レオン、追跡者（画面）

■ 場面1　裁定祭壇前
（最深部へ続く広間。古い戦闘痕と、魔力の焦げ跡。奥に、黒い祭壇へ通じる閉ざされた通路）

（重い足音。黒金の巨体が、広間の反対側から現れる。レオンが剣を抜く）

追跡者「……その剣」
追跡者「その魔力……」
追跡者「お前か」

（追跡者がレオンへ手を伸ばした瞬間。レオンの首筋から胸元へ、黒金色の細い線が浮かび上がり、追跡者の魔力と一瞬だけ繋がる。レオンの足元の影が、ほんの一瞬、黒金色に波打った）

**【カード・全員に公開】《レオンの接続痕》**

ヴィオラ「……繋がった。今、確かに」
ミレイユ「レオンさん、首の痕が……光って……！」
レオン「なんだ、これ……俺の身体が、あいつと……？」
リュシア「人違いだよ、レオン！　あいつが探してるのは、ずっと昔の誰かだ！」

（レオンの膝が、一瞬だけ折れる。それでも、柄を握り直して立つ）

レオン「……まだだ」
レオン「まだ、終わってない」
ガルド「レオン、下がれ！」

（追跡者が床を叩く。天井が崩れ、広間が三つに割れていく）

**【画面】LIVE SELECTION ― 祭壇前の崩壊**（20秒・相談不可）

```
A レオンと共に戦う
B 祭壇及び周囲を急いで探索・確認する
C 相手の名前と殺人者を叫ぶ ―― 追跡者の生前の名と、その者を殺した者の名
  （Cを選んだ人は、名前を二つ選ぶ。分からなければ「分からない」を選ぶ。被害は小さい）
```

**【画面・結果のあと】** 分断された。ここからの相談は密談で行う（同じ場所の仲間とだけ・5分）。

■ 場面2　崩れゆく祭壇前（結果表示のあと、全員）

（落ちてくる石の中、レオンが追跡者の正面へ出る。追跡者の一撃を剣で受け止め、押し返す）

レオン「こっちだ、化け物！」
レオン「探してるのは俺の剣だろう！　来いよ！」

（追跡者の咆哮。怒りに満ちた二撃目が、剣ごとレオンを薙ぎ払う。レオンの身体は崩れた壁の向こう、黒い祭壇の闇へ吹き飛ばされて消える）

ミレイユ「レオンさん――！」
ガルド「レオン！」

（瓦礫が降りそそぐ。三つに割れた広間で、それぞれが、それぞれの場所に取り残される）

（→ 組ごとの場面と密談へ）
