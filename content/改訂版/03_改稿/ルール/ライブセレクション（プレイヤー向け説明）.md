# ライブセレクション（プレイヤー向け説明）

> P1のチュートリアルで画面に表示する文。プレイヤーに配ってよい。

## チュートリアル表示文（P1）

```
LIVE SELECTION ― とっさの判断

探索中や戦闘中に、この表示が出ることがある。
考える時間はわずか。仲間と相談はできない。
自分の画面で、一つだけ選ぶ。

・人数が条件の選択肢は、同じものを選んだ仲間が揃えば成功する。
・能力の合計が条件の選択肢は、選んだ仲間の能力を足して判定する。
・能力値が条件の選択肢は、自分一人の力で判定する。
・難しい選択ほど、成功したときの見返りが大きいことがある。
・安全な選択肢もある。ただし何も得られない。

時間切れは「様子を見る」扱いになる。
```

## 基本のきまり

1. 表示が出たら、制限時間（30秒・20秒・15秒）のうちに一つ選ぶ。押した瞬間に決まり、変えられない。
2. 全員が選び終わるまで、誰が何を選んだかは見えない。
3. 結果は全員同時に表示される。HP・MP・功績の増減も表示される。
4. 行動不能（HP0）の人は自動で安全策になる。
5. リュシアの技能《限定解除》（MP3）を使うと、その回だけ2人分として数えられる。選ぶ前に設定する。

## 三種類のライブセレクション

| 種類 | いつ出るか | 特徴 |
|---|---|---|
| **部屋のライブセレクション** | 危険のある部屋に初めて入ったとき。その部屋を探索した人だけが参加 | **仲間と一緒にいれば、協力の選択肢で功績・宝・記録が手に入る**。一人だと専門の選択肢か退避しかないことが多い |
| **分断のライブセレクション** | P3・P6・P9の終わり。全員参加 | **退避はない**。三つの選択肢それぞれが、別々の場所への道になる。選んだ後、同じ場所の仲間と密談する |
| **追跡者との遭遇・決戦** | 追跡者とぶつかったとき／P12 | 押し返す・誘導する・離脱するなど。決戦では共有した攻略情報で必要人数が減る |

## 分断のライブセレクションについて

- 三つの選択肢は、結果を知らされないまま選ぶものもある。
- 時間切れになった人は、迷っているうちに最も人の少ない場所へ流される（少しダメージを受ける）。
- 分断の後の密談は5分。次のフェイズの始めに全員が合流する。
- 一人だけの場所に流れ着いたときは、密談の代わりに、その場で一人きりの場面を読み、その場所を1回調べられる（2分）。

## 部屋のライブセレクションについて

- 一人で危険な部屋に入ると、協力の選択肢は成功しない。そのときは得意な能力に賭けるか、退避するか。
- 仲間と同じ部屋を選ぶと、そのフェイズに回れる部屋の数は減る（同じ部屋なら一人ずつ深く調べられる）代わりに、協力で手に入るものが増える。散るか固まるかは作戦会議で決める。
