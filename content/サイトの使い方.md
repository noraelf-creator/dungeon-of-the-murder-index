## 見せる範囲の印（いちばん大事）

作者の指示（11/7）：「HTMLは必ずPL達に見せる情報とそうではないものはみて分かるようにしておいてください。基本PLがみてそこから判断できるかを確認するので」。

本文の段は、全部が次の5つのどれかの枠に入っている（枠の左の色の線と、上の札で分かる）。

| 印 | 色 | 意味 | 例 |
|---|---|---|---|
| ◎ PL・全員が見る | 緑 | プレイヤー全員が見る・聞く | 共通HO、読み合わせの本文、全員に配るカード、ルール・進行表・スキル一覧、ゲームの画面に出る文 |
| ◆ PL・本人だけ：（名前） | 青 | その人だけが見る。札にだれの物かを書く | 各自の HO・追加HO、本人だけに届くカード（専門の見立て・ミクシィだけの記憶 など） |
| ◇ PL・その場にいた人だけ | 橙 | その場にいた人だけが見る。札に条件を一言 | その部屋を調べた人、同じ組の人、同行中の人、部屋LSで報酬を得た人 |
| ■ GMだけ | 赤 | プレイヤーには見えない。**赤い枠でたたんである**（開く前から「GMだけ」と分かる） | 真相、正解、判定の決まり、結果の分かれ、【GM】の注、追跡者の狙いの順 |
| ▲ 制作 | 灰 | 作りの記録。たたんである | 変更の記録、決めごと、資料の書き方の説明、旧版 |

- **カード**は1枚ずつ印が付く。札の下の点線の枠に「どこで（部屋・深度）／いつ・条件／共有できるか」を書いた。だれが・どこで手に入れるかは、原稿のカードの見出しと【GM】の注、手がかりマップ、ゲームの data.js（だれにだけ届くか・共有できないカードの表。`content/_ゲームのカード表.json`、ゲーム e8a0fc8（本番 388dd3c1 と同じ。11/11 に作り直し）から作った）から取った。
- 「推理のあと」の札：真相の読み合わせ（R21）・ED（R22・R23）など、最終戦のあとに読む物。
- 文の途中の【GM】は、赤い小さな札（GMだけ）になっている。【2026-11-07 …】【作者修正】などの制作の印は、灰色の小さな札。
- 左の一覧のページ名の前にも、そのページのいちばん多い印（全員／本人の名前／その場／GM／制作）が付く。右の小さな点は、そのページにほかの印の段もあること。
- ページの上には、そのページの段の数を印ごとに出している。

## 「表示」の切り替え（画面のいちばん上）

| 表示 | 何が出るか |
|---|---|
| すべて表示（GM・制作も） | 全部（作者・GM用） |
| プレイヤーが見る情報だけ（4人分） | ◎◆◇の段だけ。■GMだけ・▲制作・制作の札・文の途中の【GM】を隠す。左の一覧も、プレイヤーが見る段の無いページ（真相・GM進行ガイドなど）を隠す。全文検索もプレイヤーの段だけを探す |
| プレイヤー：ミレイユとして見る（ほか3人も） | 上に加えて、**ほかの人の◆本人だけ**も隠す（その人の HO・本人だけのカードだけが残る） |
| 「推理のあと（真相・ED）も隠す」 | プレイヤー表示のときだけ出る。既定で入っている |

- ◇その場にいた人だけの段は、プレイヤー表示でも出る（だれがその場にいたかは遊び方で変わるため）。札の条件を見て、「その場にいた人だけが知る」と読む。
- 切り替えはこの端末に覚える。URL の後ろに `?view=pl`（または `?view=pl:mixi` など）を付けて開いても切り替わる。
- 確かめ方の例：「プレイヤーが見る情報だけ」にして、カード・HO・読み合わせのページを読み、真相が推理できるか。全文検索で「【GM】」と打つと、プレイヤー表示では見つからない。

## 2026-11-15 の変更：2列（左＝本文／右＝実画面）と、作者が足す文

作者の指示「左が現在の本文、右にプレイ画面の実際の画像」「HTMLに欄の追加と文章の追加ができるように。私がそこに新たらに欄を追加するときなどに使用する」への対応。

| 場所 | 何が出るか |
|---|---|
| 左の列 | いまの本文（訂正・削除の反映後）。その下に、AI案を「AI案（参考・未採用）」として**折りたたんで残す**（消していない。`content/_ai_proposals.json` も変えない） |
| 右の列 | その段の**実際のゲーム画面**。上の札に版（gameCommit）と「本番／未デプロイのプレビュー」、撮影した日時。まだ撮っていない所は「撮影待ち」と書き、ほかの画像で埋めない |
| 幅が狭いとき（1200px以下） | 1列（本文 → 画像）。印刷では画像を出さない |
| 各段の「＋ここに足す」 | 作者の段落・節・ページを、その位置に足す（前の段の後ろ・ページの先頭・末尾・作者の文の後ろ） |
| 左の「作者のページ」 | 作者が作ったページ（`#/u-…`）。題を変えてもURLとIDは変わらない |
| 「作者が足した文」のタブ | 足した文の一覧。既存の「修正案」の一覧・「場所不明」の数・書き出しには**混ぜない**。位置が分からなくなった追記は「位置不明の追記」にまとめて出す（消さない・隠さない） |
| 書き出し | JSON（`dom-author-layer-v1`）と Markdown。原稿へは自動で入らない（統括が確認して反映する） |

- 足した文は**このサイトの別レイヤー**（共有保存と、この端末の下書き）にだけ入る。原稿（05_完成版）とゲームは変えない。
- 既定の見せる範囲は「▲制作」。プレイヤー表示・本人表示では出ない（漏れ0件をプログラムで確かめる）。
- 足した文は、そのまま文字として出す（HTMLとして解釈しない）。`<script>` のような文字を書いても、文字のまま出る。
- 字数の上限：**1つの追記の本文は 10,000 字まで**。保存する1行（メモ）全体では 12,000 字まで（表題・位置・設定を含む）。超えると保存できないので、入力欄に残りの字数を出す。長い文は節を分ける。
- 「ゲームの全文字」のページの文字は、**ゲームのコードから抜いた文字**（読むだけ）。作者が足す文（上の追記レイヤー）とも、原稿の本文とも別で、混ぜない。
- 共有保存が競合したとき（別の端末で同じ所を更新）は、上書きせずに知らせ、**書いた下書きは消しません**。通信できないときも端末内の下書きとして残します。
- **「送信済・確認未完了」や通信エラーが出たとき**は、ネット接続が戻ったあと「最新を取得」を押し、読み戻しができてから編集・保存を再開してください。未確認のまま別の文章へ書き直したり、一括送信を繰り返したりしないでください。確認待ちの下書きは保留されることがありますが、消しません。
- 編集キーを解除していないときは、保存先は**この端末だけ**です。別の端末でも見るには、編集キーで解除して共有し、「読み戻しで確認しました」の表示まで確かめてください。

## 3列で見比べる（カードとHO）

（前の版の説明。2026-11-15 に上の2列へ変えた。AI案は左の列の下に折りたたんで残している）

カードとHOのページは、1項目ごとに3列で並ぶ。

| 列 | 中身 |
|---|---|
| 左 | いまの本仕様（作者の訂正・削除を反映した本文）。ここに「✎」「直す」「削除」が出る |
| 中 | 同じ項目のAI案（校正・削減・削除の提案）。札（削除提案・削減案・校正案・現行維持）、字数（現行→AI案・差）、理由、保護した推理事実 |
| 右 | 対応する実際のゲーム画面。上の札に、どの版か（プレビューか本番か）を出す |

- 上の「AI案を隠す／並べる」「実際の画面を隠す／並べる」で、列を減らせる。ページの上に、そのページの字数と、カードなら固定目標（9,956字）までの残りを出す
- AI案は**候補**で、本文には入っていない。「AI案を『直す』欄に写す」を押すと、左の本文の入力欄に案が入る（そこから自分で直して保存する。押しただけでは保存されない）
- 「⚠ 原稿更新済み（旧版へのAI案）」が出た案は、原稿が変わったあとの古い案。採用しない
- 「AI案はまだありません（未生成）」は、その項目の案がまだ作られていないという意味（空の案ではない）
- プレイヤー表示に切り替えると、AI案と実画面は隠れる（GMの言葉が混ざることがあるため）
- 画面が狭いときは、列ではなく、項目ごとに 本仕様→AI案→実画面 の順で縦に積まれる

## 修正案の残し方

1. 本文の直したい段落・台詞・表の行にカーソルを合わせると、右端に「✎」が出る（スマホでは、その行を一度タップする）
2. 「✎」を押すと右のサイドバーが開き、その箇所の修正案を書ける
3. 書いた内容は自動で保存される。「反映済み」にすると、一覧で区別できる
4. 修正案のある箇所には、本文の右端に印が付く（黄色＝未反映、緑＝反映済み）
5. 右のサイドバーの「このページ」「すべて」で一覧を見られる。「すべて」から、未反映の修正案をMarkdownで書き出して、Claudeに渡せる
6. 前の版（10/06）に書いた修正案は、「参照・旧版（10/06）」の同じページに付いたまま残っている

## 共有保存（編集キー）

- 閲覧と修正案の表示には、キーは要らない
- 上部の「編集キー」から作者用の編集キーを入れると、修正案が共有保存（Cloudflare D1）に保存され、ほかの端末でも見られる。解除は30日間有効
- キーを入れていない間も、修正案は「この端末の下書き」として残る。あとで解除すると「下書きを共有へ送る」で送れる
- 同じ箇所を別の端末で同時に直した場合は、上書きせずに知らせる
- 保存先はこの作品専用（ほかの作品のメモとは混ざらない）

:::note 公開について
このサイトは、URLを知っている人なら誰でも読める（GitHub Pages の公開サイト）。真相やGM情報も載っているので、プレイヤーにURLを教えないこと。修正案に個人情報やパスワードを書かないこと。ゲームの合言葉もここには書かない。
:::
