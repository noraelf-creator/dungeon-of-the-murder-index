## B. 灰嶺の災厄（12年前）【作者指示＋追加設定】

| 時期 | 出来事 |
|---|---|
| 12年前・初日 | 灰嶺の古い鉱山で魔導核の近くに閉じ込められたユーリ（17）を、ガルドとレオン（24）が救出。本人の願いで灰嶺の町へ連れ帰る |
| 3日後 | ユーリに黒金色の線。接続がユーリを通して町へ伸び、黒金の獣が湧く。町の三分の一、二百人あまりが死亡 |
| 同日 | ガルドとレオンが最前線で戦い、十歳のミレイユを救う。最後に二人でユーリを斬り、災厄が止まる |
| 数週間後 | 灰嶺教会の司祭アドリアン（ミレイユの養父）が魔導院で証言。証言者名は伏せられる。二人は「灰嶺の英雄」と呼ばれる |
| 同時期 | 魔導院の調査官が二人に断脈剤を一本ずつ渡す。レオンは川へ捨て、ガルドは持ち続ける。その夜の約束「俺がああなったら止めろ」 |
| 11年前 | 『灰嶺魔力災害調査報告』刊行。接続者搬出禁止令。断脈剤は魔導院の管理薬になる |
| 以後10年 | 灰嶺の核の研究から魔力薬の量産が進む |
| 3年前 | レオンは「斬らずに救う方法」を探してギルドの遺跡調査班へ。ガルドは前線でSランクを目指す。コンビは解消、親友のまま |
