# ライブセレクション（プレイヤー向け説明）

> P1のチュートリアルで画面に表示する文。プレイヤーに配ってよい。

## チュートリアル表示文（P1）

```
LIVE SELECTION ― とっさの判断

探索中や戦闘中に、この表示が出ることがある。
考える時間はわずか。仲間と相談はできない。
自分の画面で、一つだけ選ぶ。

・人数が条件の選択肢は、同じものを選んだ仲間が揃えば成功する。
・能力の合計が条件の選択肢は、選んだ仲間の能力を足して判定する。
・能力値が条件の選択肢は、自分一人の力で判定する。
・難しい選択ほど、成功したときの見返りが大きいことがある。
・退く選択肢もある。傷は浅くて済むが、何も得られない。

時間切れは「様子を見る」扱いになる。様子を見るのは、たいてい損になる（部屋では退いたのと同じで、浅い傷を負い、何も得られない）。
```

## 基本のきまり

1. 表示が出たら、制限時間（30秒・20秒）のうちに一つ選ぶ。押した瞬間に決まり、変えられない。
2. 全員が選び終わるまで、誰が何を選んだかは見えない。
3. 結果は全員同時に表示される。HP・MP・功績の増減も表示される。
4. 行動不能（HP0）の人は自動で安全策になる。
5. ミクシィの技能《限定解除》（MP3）を使うと、その回だけ2人分として数えられる。選ぶ前に設定する。

## 三種類のライブセレクション

| 種類 | いつ出るか | 特徴 |
|---|---|---|
| **部屋のライブセレクション** | 危険のある部屋に初めて入ったとき（危険のある部屋は、全部の部屋ではない）。その部屋を探索した人だけが参加。一つの部屋で一回だけ（一度起きた部屋では、誰が入っても、もう起きない。探索はできる） | 選択肢は三つ。**協力**：選んだ仲間（2人以上）の能力の合計で判定する。**中間**：選んだ人の能力の合計で判定する。得意な人なら、一人でもぎりぎり届く。**退避**：少し傷を負い、何も得られない |
| **分断のライブセレクション** | P3・P6・P9の終わり。全員参加 | 選んだ行動によって、パーティがばらばらの場所に分かれる |
| **追跡者との遭遇・決戦** | 追跡者とぶつかったとき／P12 | 遭遇では、画面に問いが一つ出る。各自が答え、当たればかわせる（傷なし）。外れると傷を負う。決戦では何度か続けて選ぶ。同じやり方・同じ答えを**2人以上**が選べば、その回は成功。力で押し通す選択肢は、それを選んだ人の今の能力の合計が足りていれば効く（ばらばらに動くと、数も力の合計もそろわない）。共有した攻略情報は、うまくいかなかったときの被害を防ぐ |

## 分断されたら

画面に「**分断された。**」と出る。
P3とP9の分断では、何も選ばずに時間が過ぎると「**様子を見る**」になる（その場で動かずに様子を見る。様子を見た人どうしが同じ組になる）。
同じ場所にいる仲間と、その場所の場面を読む（一人だけなら、その場を1回調べられる）。
分断されると《Disgord》が切れる。そのあいだは、**同じ場所にいる仲間とだけ相談できる（密談フェイズ・5分）**。ほかの仲間の様子や持ち物は見えない。ヴィオラが《Disgord》を直すと、全員がまた合流する。

## 部屋のライブセレクションについて

- 一人で危険な部屋に入ると、協力の選択肢は成功しない。そのときは中間の選択肢で得意な能力に賭けるか、退避するか。
- 仲間と同じ部屋を選ぶと、そのフェイズに回れる部屋の数は減る（同じ部屋なら一人ずつ深く調べられる）代わりに、協力で手に入るものが増える。散るか固まるかは作戦会議で決める。
