## フェイズ別の進行

### 開始前（10分＋5分）
1. HO確認10分。支給品を選ぶ（ガルドは回復薬で固定）。
2. R00 オープニングを読む。**ここで「灰嶺の英雄」とトマの報告（黒金の光を浴びた）を全員の耳に入れる。**

### P1（10分）
1. R01 → 「避けろ！」の回避カットイン → チュートリアル表示 → LS（30秒）。
2. 結果表示 → R02。入口が崩れ、追跡者は入口大広間で再構築を始める。
3. P2へ直行（P1は共有なし）。

### P2（18分）
- 通常の探索フェイズ。救難所（U7）は閉鎖隔壁で行けない。マップには「隔壁の向こうから微かな人の気配」とだけ出す。
- 部屋LSが起きる部屋に一人で入った人は、協力の選択肢が成功しない。作戦会議で「散るか固まるか」を話題にさせる。

### P3（22分）
1. 通常の探索 → 帰還（各自の結果を確認）。**全体共有は行わない**。
2. 中央封鎖路に集合（U11固定情報を全員に）→ R03。
3. 分断LS（20秒）→ 結果 → 組ごとにR04／R05／R06 → 密談5分。
4. 密談中の注意：同じ組の者だけが話す。別の組の画面は伏せる（アプリでは組ごとのチャット表示）。
5. 一人だけの組は、密談の代わりにR24（独白＋その場を調べる、2分）。P3のC組はレオンがいるので一人でも密談5分（R24の「レオンへの質問と返事」を使う）。

### P4（25分）
1. ガルドに追加HO②を渡す（読み終わるまで待つ）。
2. R07 救難所の扉。**ここがトリックの核心。入室の順番（ガルド→ミレイユ→リュシア→ヴィオラ）と、薬棚が扉のすぐ脇であること、瓶に封蝋があることを、読み飛ばさせない。** 読み終えたら、公開ログに入室順を記録する（R07末尾）。
3. ミレイユに追加HO②。
4. 全体共有10分（P3の組の情報もここで共有可能）→ 作戦会議 → 探索 → 帰還 → 共有。
5. レオンの同行が解禁。追跡者の巡回が始まる。

### P5（18分）
- 通常の探索。レオンを1人が連れて行ける。

### P6（25分）
1. R08 場面1（門の前、レオンの悪寒）。U12固定情報を全員に。
2. 作戦会議 → 上層の探索 → 帰還（全体共有なし）。
3. R08 場面2（窮地）→ 分断LS（20秒）→ 結果は隠したまま着地 → R09／R10／R11 → 密談5分。
4. レオンが加わる組を決める（最少人数、同数規則あり）。結果画面に「レオンは○○の組へ（理由）」を必ず表示する。

### P7（22分）
1. 全員が守護研究前室で合流。L0固定情報を全員に。
2. **レオンがいた組だけ**でR12（打ち明け話）。他の組はその間待つ（または画面を伏せる）。
3. 全体共有10分 → 作戦会議 → 探索 → 帰還 → 共有。

### P8（18分）
- R13（震える手）→ 通常の探索。

### P9（22分）
1. 作戦会議 → 探索 → 帰還（全体共有なし）。
2. 祭壇前に集合 → R14 場面1（接続痕を全員に公開）→ 分断LS（20秒）。
3. ガルドがDを選んだら追加HO③を先に渡す。
4. R14 場面2（全員）→ R15／R16／R17 → 密談5分。

### P10（18分）
1. R18 → 《背後からの一撃》を全員に。
2. 各自1回：遺体・所持品・現場の調査、またはダンジョン探索。
3. 全体共有10分。

### P11（30分）
1. 各自1回：最終調査（遺体・所持品・現場・支給記録・台帳・素材出所）または休息。
2. **議論20分**。
3. 推理回答3分（死因／時期／手段／犯人）。
4. 投票1分（4人の誰か、または事故）。

### P12（30分）
1. R19 → 決戦前会議5分 → 最終LS①〜⑤（緊急⑥は1回まで）。
2. R20 名前フェイズ。
3. 結果表示 → 戦利品の整理（ヴィオラは守護核の欠片を持ち帰るか決める）→ 功績。
4. R21 真相 → R22 共通ED → R23 個別ED。

## 推理の山場で、GMが確認しておくこと

- **P4の入室順**：議論で「誰が最初に入った？」と聞かれたら、R07のとおりに答える（ガルド→ミレイユ→リュシア→ヴィオラ）。
- **瓶の封蝋**：救難所は古代の施設なので、ギルドの封蝋つきの瓶が棚にあること自体がおかしい。気づいたプレイヤーは褒める。
- **ガルドの2本目**：支給記録で2本。アプリの公開ステータスで、現在の所持数は全員に見えている。
- **リュシア・ミレイユ疑惑**：見つけた／飲ませた二人は疑われやすい。入室の順番と、《空き瓶の封蝋》（入る前に細工された＝入る前に殺す理由を持ち得た者）で晴らせる。回復薬の数だけでは晴れない（使ったかどうかは本人にしか分からない）。
- **遺体の専門判定**：P10で遺体を深度2まで調べたら、聖女・魔女に技能を使うよう促す。技能で専門判定を得ると深度3へ進むので、残りの手番を時期（遺体4）や所持品・現場へ回せる。
