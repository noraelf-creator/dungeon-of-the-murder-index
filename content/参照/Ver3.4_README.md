# ダンジョン・オブ・ザ・マーダー
DUNGEON OF THE MURDER — Ver.3.4 デザイン・演出統一

## 起動
ゲーム本体は同一ブラウザの4タブ用。制作メモだけは下記Cloudflare確認盤で別端末同期できます。
ZIPを展開してプロジェクト直下で起動（Pythonがある場合）：

```
python -m http.server 4176 --bind 127.0.0.1 --directory dist
```

http://localhost:4176/ を新しい4タブで開きます。dist/index.htmlの直接起動は可能ですが、file://の共有保存はブラウザ依存。Web Locks対応localhost推奨。dist/assetsも必要です。

## 遊び方
1. 新規パーティを作り、集合絵下のPARTY IDを残り3タブで入力。コピー／共有ボタンがあります。
2. 各自のPCを選択。同じPCを再クリックで解除。4人決定でHOへ。
3. 本人HOと支給品を確認。HO目安10分、全員の準備完了で開始。
4. 上部4PC（救助後レオン含む5人）は公開ステータスとスキル確認用。本人操作は最右端の「本人専用」から目標／所持品／HO／スキルを選びます。下段左は探索、右は情報です。
5. 情報は親とPRIVATE／MULTI／SHAREDをそれぞれ開閉。各カードも閉じたタイトル／場所／状態から個別に展開。量が増えるとページ下へ伸びます。PRIVATE＝貴方のみ、MULTI＝未共有の探索情報、SHARED＝共有済み。部屋を押すとその部屋のSHAREDだけを表示し、「すべてのSHARED情報を表示」で解除できます。
6. 最右端は「本人専用／ログ」の切替式。ログは個別が上、公開が下の固定枠内スクロール、最新が先頭。全体を収納すると「サイドパネル」ボタンだけ残り、メイン2列が広がります。モードはそのタブ内で保持されます。
7. 地図で探索先を選び、全員決定で探索開始。P4救出後に同行と誘引が解禁。
8. 発見品は行動可能な同室者の現在の器用が最大のPCへ。同値はPC順。バフ・装備込み、罠専用の精密動作は除外。実取得者がoriginalFinderです。
9. 帰還RESULTで本人の情報・品・同室者を確認。同室者の専用情報は存在描写のみ。4人全員が「次へ」で情報共有へ。
10. 情報共有の説明欄に残り時間と全員状況、「次へ」。参加可能者全員で進行、最大10分。カード共有は確認後に公開。
11. LSは2.2秒カットイン後、補助設定を先に選び、大きな選択肢を1回押すと即回答。再確認はありません。結果文の後にHP等の前後と増減を表示。
12. 通常の技能・品は対象／場所と確認を経て実行。個別の使用記録は関係者だけ。公開ログに一般アイテム使用先は残しません。
13. 設定から退室。閉じた本人タブは同コードで参加し、空いた参加枠の引き継ぎが可能です。

## 公開情報ボードと演出
通常情報欄最上部の「公開情報ボードを開く」（P10/P11と決戦前会議、ヘッダーにも入口）で、共有済み情報を一覧／マップ／時系列／ピン留めの4モードから確認できます。分類・検索付き。カードを押すと既存全文を表示し、閉じる／Escで戻ります。開いてもタイマーは止まりません。
通常SHAREDは場所とタイトル中心のコンパクト表示。開くと1行要約＋本文です。
☆／★はパーティ全員共通のピン留め。モード・検索・閲覧中のカードは各タブで独立します。名前フェイズでは共有済み古代情報だけを閲覧でき、ピン変更もできません。
時系列は共有カードに書かれた時期だけです。未共有の出来事や死亡時期を自動補完しません。関連カードジャンプはありません。
技能は約2秒の顔アップ＋名前・役職・技能名の連続文字演出へ変更。使用者と技能名は全員に、対象と効果詳細は既存の本人個別ログだけに残ります。OSの「動きを減らす」設定にも対応しています。
