# キャラ選択画面の文（タイトル〜HO を読む画面）

<!--vis:make-->

:::note このページについて
ゲームの最初の画面（タイトル・キャラクターを選ぶ・待つ・HO を読む）に出る文を、画面に出る順に並べた（2026-11-13、ゲーム e8a0fc8 の app.js と原稿から写した。写した文がゲームのコードに同じ形であるかは、作るたびに機械で確かめている）。
4章（人物の紹介）だけが原稿にあり、ほかはゲームのコードに直接書いてある。直したい文は、この段で「直す」か「削除」を使えば、原稿またはゲームのコードへ反映する。
右の「実際の画面」に、ゲームで撮った画面が並ぶ（撮れた分）。
:::

## 1. タイトル画面（同じブラウザで遊ぶ版）

<small>部屋に入る前の最初の画面。題の絵の下に並ぶ。</small>

| どこ | 文 |
|---|---|
| 見出し | 部屋を作る |
| 説明 | 同じブラウザで4つのタブを開き、各自が自分のキャラクターのタブを使う。 |
| ボタン | 新しい部屋を作る |
| 見出し | パーティに入る |
| 入力欄の例 | パーティコード（例 AB12-C3） |
| 注 | 途中で抜けた人も、ここにパーティコード（画面のいちばん上の右）を入れて入り直せる。 |

## 2. タイトル画面（オンライン版）

<small>4人がそれぞれ自分のパソコンで開く版。</small>

| どこ | 文 |
|---|---|
| 説明 | 部屋を作ったら、画面の上の部屋コードを、いっしょに遊ぶ3人に送る。4人それぞれが自分のパソコンで開く。 |
| GM ありの欄 | GM ありで遊ぶとき |
| GM ありの説明 | 部屋を作った人が5人目の GM になる（席には着かない）。GM の画面では、全員の状態・残り時間・読み合わせの原稿を見ながら、一時停止・時間の延長・次の段へ・お知らせができる。遊ぶ4人は今までと同じ。 |
| ボタン | GM ありで部屋を作る（自分は GM） |
| 入力欄の例 | 部屋コード（例 AB23CD） |
| 注 | 途中で抜けた人も、ここに部屋ID（ゲーム画面のいちばん上の右）を入れて入り直し、「代役で入る」から自分のキャラクターを選ぶ。 |

## 3. キャラクターを選ぶ（部屋に入ってすぐ）

<small>4人の立ち絵が並び、右の欄に「救助隊の通話」。人物にマウスを乗せると、右の欄がその人の紹介（4章）に替わる。</small>

| どこ | 文 |
|---|---|
| 見出し | キャラクターを選ぶ |
| 見出し（始まった後に入り直すとき） | 再参加するキャラクターを選ぶ |
| 右の欄の題 | 救助隊の通話 |
| 右の欄の案内 | 人物にマウスを乗せると、ここに紹介が出る。押すと、その人物で入る。 |
| 席の札（空き） | 空き |
| 席の札（ほかの人が選んだ） | 参加中 |
| 紹介の下の一行（空き） | 押すと、この人物で入る。 |
| 紹介の下の一行（ほかの人が選んだ） | 参加中（ほかの人が選んだ）。 |
| ボタン | 管理者モードで開く／別の部屋へ |
| 注 | このパーティコードを他のタブで入力すると、同じ部屋に入れる。 |

## 5. 参加者を待っている（選んだあと）

<small>自分の人物が前に出て、ほかの3人には「参加中」「空き」の札。</small>

| どこ | 文 |
|---|---|
| 見出し | 参加者を待っている |
| 説明 | 4人がそろったら、HO を読む画面へ進む。ほかの人物にマウスを乗せると、その人の紹介が出る。 |
| 自分の紹介の下の一行 | あなたの人物。4人そろったら HO を読む。 |
| 空きの席の一行 | まだだれも選んでいない。 |
| ボタン | 選び直す／4人そろった → HOを読む |

## 6. HO を読む画面（4人そろったあと）

<small>左に HO（上に札）、右に支給品と準備。2026-11-13 の作者の指示（全員で「はじめに」と共通HO→各自のHO）は、まだこの画面に入っていない（実装反映メモに案）。</small>

| どこ | 文 |
|---|---|
| 上の札 | あなたのHO／共通HO／フェイズ進行表（資料の題） |
| 資料の札の小見出し | 資料 ／ 全員 |
| 自分の HO の小見出し | あなたのHO ／ 本人のみ |
| HO の中の見出し | あなたの目的／秘密／知っていること／技能／話し方 |
| 右の見出し | 支給品／準備 |
| エドガー（支給品が決まっている） | 魔力薬（決まっている。HO を読む） |
| 時間 | HO確認の目安 ｛残り時間｝ |
| 注（支給品をまだ選んでいない） | 先に上の「支給品」から一つ選ぶ。選ぶと「準備完了」を押せる |
| ボタン | HOを読んだ → 準備完了／先に支給品を選ぶ（上の欄）／全員そろった → はじめる |

## 7. 代役で入る（オンライン版・途中で抜けた人の席）

| どこ | 文 |
|---|---|
| 見出し | 代役で入る |
| 説明 | 途中で抜けた人の代わりに入れる。そのキャラクターの HO・手札・持ち物をそのまま引き継ぐ。入ったら、まず HO と手元のカードを読む。 |
| 右の欄の案内 | 「代役を待っている」席だけ選べる。人物にマウスを乗せると、ここに紹介が出る。 |
| 席の札 | 代役を待っている |
| 紹介の下の一行 | 押すと、代役としてこの席に入る。 |
| GM ありの部屋の注 | この部屋は GM あり。GM が進行を見守り、全員の画面にお知らせを出すことがある。 |
