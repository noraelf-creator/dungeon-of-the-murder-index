## B. 灰嶺の災厄（12年前）【作者指示＋作者修正＋追加設定】

| 時期 | 出来事 |
|---|---|
| 12年前・初日 | 灰嶺の鉱山が古い坑道を掘り抜き、封鎖された灰嶺分核に行き当たる。核のそばで三日閉じ込められたユーリ（17）を、ガルドとレオン（24）が救出。本人の願いで灰嶺の町へ連れ帰る |
| 3日後 | ユーリの首に黒金色の線。その夜、ユーリの影から黒金色の光がこぼれ、町の人の魔力を吸って殻だけの獣を組み上げる。斬っても光にほどけ、ユーリのそばで組み上がる。町の三分の一、二百人あまりが死亡 |
| 同夜 | ガルドとレオンが最前線で戦い、十歳のミレイユを救う。最後はレオンがユーリを押さえ、ガルドが斬る。獣はいっせいにほどけて消える |
| 数週間後 | 灰嶺教会の司祭（ミレイユの養父）が魔導院で証言。証言者名は伏せられる。二人は「灰嶺の英雄」と呼ばれる |
| 同時期 | 魔導院の使いが二人に断脈剤を一本ずつ置いていく。レオンは翌朝川へ投げ、ガルドは持ち続ける。レオン「俺がああなったら止めろ」 |
| 11年前 | 『灰嶺魔力災害調査報告』刊行。接続者搬出禁止令。断脈剤は魔導院の管理薬になる（古代の隔離規定と同じ内容だが、魔導院はそれを知らない） |
| 以後10年 | 灰嶺の核の研究から魔力薬の量産が進む |
| 3年前 | レオンは「斬らずに救う方法」を探してギルドの遺跡調査班へ。ガルドは前線でSランクを目指す。コンビは解消、親友のまま |
